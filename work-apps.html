Rams Care Data Dashboard

A dashboard that makes PBIS survey data usable.

Staff can slice survey responses by grade, section, time period, and question. The Student Insights view surfaces individual response patterns that get buried in aggregate reports, which is the one teachers actually open most often. Streamlit, Python, fast iteration over polish.

Unified Arts Website

A department website rebuilt around the tools families actually use.

The previous site was hard to navigate and disconnected from Google Classroom, which is where homework and announcements actually live. The rebuild pulls those streams in directly, so families and students see one calm interface instead of three.

Design brief I gave myself: feels like a real website, not a school website. Clear typography, calm layout, equal footing for every discipline on the homepage.

Heartbeat

A communication and data platform for the school. In progress.

Instead of bouncing between disconnected tools, spreadsheets, and email threads, Heartbeat gives staff, students, and admin a single place to share information, manage curriculum, and stay on the same page. Built in React because the interface needs to feel fast for people checking it between classes.

The staff side surfaces schedules, announcements, and curriculum. The student portal gives kids their assignments, news, and resources in a layout they can actually navigate. The admin tools handle the school-wide view. A shared communication hub ties it all together.
